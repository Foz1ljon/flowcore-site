What it does

An AI analyst in every module

CRM, warehouse, production, HR and LMS each have an “AI analyst” tab with its own role and suggested questions.

Your own AI key

Use OpenAI, Claude, Gemini, OpenRouter or any OpenAI-compatible provider. The owner or an administrator manages the key.

No personal names are sent

The AI receives metrics, rule-based findings and aggregated tables only. Customer, employee and student names are not sent.

Findings without a key

Without an AI key FlowCore still shows its built-in rule-based findings.

MCP server for AI agents

Connect an MCP-capable assistant to your company’s FlowCore server. Keys are read-only or read-write and work only on your company address.

Advice never changes records

AI analysis only explains and recommends. Changing data depends on user permissions and explicit confirmation.

Frequently asked questions

Which AI providers does FlowCore AI support?

OpenAI, Claude, Gemini, OpenRouter and other OpenAI-compatible providers, using the company’s own API key.

What is MCP?

MCP (Model Context Protocol) is a common way for AI assistants to use data and tools of other software. With the FlowCore MCP server your AI agent can read permitted reports and records.

Can the AI change my data?

The AI analyst only gives analysis and advice. An MCP agent can act only with a write key and your explicit instruction.
